# Topic 1: Loading, Cleaning and Exploring Data

---

The first step in data exploration is the process of loading, cleaning and exploring data. Each of the software packages we use has a different mechanism for this and our goal for this Topic is to understand how to load and complete basic manipulations with our datasets.

#### **Learning objectives**

In this lesson, we'll focus on developing the basic essential skills for importing,  manipulating and visualizing your data across Excel, R and QGIS.

- Locate and successfully import datasets into Excel, R (via Positron), and QGIS using correct file formats and import procedures.
- Apply appropriate formatting techniques to ensure data is clean, consistent, and ready for analysis, including handling dates and times, and setting up data for visualization in each platform
- Aggregate and plot data within Excel using Pivot Tables and Charts
- Create simple visual representations of data in Excel and R, as well as maps in QGIS that support initial data exploration
