# Topic 3: Conditional logic, conditional calculations, and deterministic modelling

---

In this topic, we’ll start moving beyond just organizing data and begin using it to actually do things. We’ll look at how formulas and conditional logic can help us create new variables and classify observations.  We’ll then build on those ideas by creating some simple deterministic models, where we use a set of rules or equations to model our data.
