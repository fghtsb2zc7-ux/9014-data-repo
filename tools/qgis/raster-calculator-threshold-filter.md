# Filter a raster to cells above a threshold with the Raster Calculator

## Purpose
Creates a new raster that keeps the original pixel values only where they exceed a cutoff (e.g. species-distribution probability > 0.5) and sets every other pixel to 0. A plain comparison (`"layer@1" > 0.5`) gives a binary 1/0 raster instead; both variants are shown. Course skills checklist items 18-19 ("use the Raster Calculator to create a new raster", "classify raster cells using a cutoff value") [page technical-skills-checklist.md].

## Steps
1. Load the raster(s) (course: drag `Carcinus maenas.tif` and `Ciona intestinalis.tif` into the map; they come in as greyscale "Band 1 (Gray)" layers in EPSG:4326) [video qgis-raster-calculator @00:06] [page topic-2-transforming-and-wrangling-data.md]. Loading/symbolising rasters is covered in [QGIS - Raster import](../../transcripts/qgis/qgis-raster-import.md).
2. Optional: check pixel values with the Identify Features tool; the Identify Results panel shows `Band 1` (e.g. `2.37425e-06`, `0.428675`) [video qgis-raster-calculator @00:42] [frame].
3. Open `Raster > Raster Calculator...` (first item of the Raster menu) [video qgis-raster-calculator-with-two-raster-layers @02:32] [frame]. The dialog is titled "Raster Calculator".
4. In "Raster Bands", double-click the band to use (e.g. `Carcinus maenas@1`); it is inserted in quotes into "Raster Calculator Expression" [video qgis-raster-calculator @01:57].
5. Click the `>` operator button (or type it) and type the cutoff `0.5` (values are probabilities 0-1) [video qgis-raster-calculator @01:57]. The status line under the box must read "Expression valid" [frame].
   - Stop here if you only want a binary raster (1 = above cutoff, 0 = below) [video qgis-raster-calculator @02:38].
6. To keep the original values: wrap the comparison in brackets, add `*`, then double-click the same band again, giving `("Carcinus maenas@1" > 0.5) * "Carcinus maenas@1"` [video qgis-raster-calculator @02:38-03:17] [frame @03:12].
7. Under "Result Layer" choose ONE:
   - tick `Create on-the-fly raster instead of writing layer to disk` (the course choice; "Layer name" shows "Autogenerated from expression"; the result lives only in the project) [video qgis-raster-calculator @03:53] [frame @03:52]; or
   - leave it unticked and set `Output layer` via the `...` button with `Output format` = `GeoTIFF` to save a file [video qgis-raster-calculator @03:17] [frame].
8. Leave Extent (default "current: <layer>", N 90 / W -99 / E -40 / S 25 for the course rasters) and Resolution (Columns 708, Rows 780) as filled in [frame @03:52]. Click `OK`.
9. The new layer appears named after the expression (e.g. `("Carcinus maenas@1" > 0.5) * "Carcinus maenas@1"`) in greyscale. Turn off the original layer [video qgis-raster-calculator @03:53].
10. Restyle: double-click the new layer > `Symbology` > Render type `Singleband pseudocolor`, Color ramp dropdown > `Viridis` (any ramp), `Apply` [video qgis-raster-calculator @04:30] [frame @04:52].
11. Hide the 0 cells by making the colour of value 0 fully transparent (see [raster-set-value-transparent](raster-set-value-transparent.md)), then `Apply`, `OK` [video qgis-raster-calculator @05:09-05:50].

## Formulas / expressions / code
```
"Carcinus maenas@1" > 0.5
```
Binary output: 1 where the pixel value of band 1 of layer "Carcinus maenas" is greater than 0.5, else 0 [video qgis-raster-calculator @02:22 frame].
```
("Carcinus maenas@1" > 0.5) * "Carcinus maenas@1"
```
The bracket yields 1/0; multiplying by the original band keeps the original probability where it is > 0.5 and 0 elsewhere [video qgis-raster-calculator @03:12 frame]. Band references are `"<layer name>@<band number>"` in double quotes. Full syntax: [expression-reference.md](expression-reference.md#raster-calculator-syntax).

## Verify
- Status line under the expression shows "Expression valid" and `OK` is enabled [frame].
- New layer is listed in Layers; min 0, max ≈ 0.93 for Carcinus maenas (legend 0.930706) [frame @04:22].
- Identify Features on a coastal cell above 0.5 returns its original value (e.g. `0.650805473327637`); cells below return 0 [frame @05:12].
- After transparency, only high-probability coastline (Nova Scotia, Bay of Fundy, Gulf of Maine for green crab) is coloured [frame @05:52].

## Pitfalls
- "Expression invalid" appears while the expression is incomplete (e.g. `(... > 0.5) * `) — finish it before clicking OK [frame @03:02].
- Without the `* "band"` part the output is only 1/0, not the original values [video qgis-raster-calculator @02:38].
- The new raster comes in greyscale; it must be restyled to pseudocolour [video qgis-raster-calculator @03:53].
- On-the-fly rasters are not written to disk ("won't save it as a GeoTIFF"); untick the box and give an Output layer if you need a file [video qgis-raster-calculator @03:53].
