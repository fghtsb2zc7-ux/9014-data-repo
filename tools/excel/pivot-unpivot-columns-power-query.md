# Reshape data between long and wide format with Pivot Column / Unpivot Columns in Power Query

## Purpose
Turn long data (one row per industry per year) into wide data (one row per industry, one column per year) with **Pivot Column**, and turn it back with **Unpivot Columns**. Wide data makes year-vs-year comparison and some analyses (e.g. PCA) easier; long data is better for most analysis/plotting. Equivalent to `pivot_wider()` / `pivot_longer()` in R (see [../r-positron/pivot-longer-and-wider.md](../r-positron/pivot-longer-and-wider.md)). Checklist items 13-14 [page technical-skills-checklist.md].

## Steps
### A. Open the data in Power Query
1. In a blank workbook click `Data > Get & Transform Data > From Text/CSV` (the course clicks Get Data/From Text/CSV on the Data tab). [video excel-pivoting-columns @01:12; frame]
2. In the "Import Data" dialog browse to the NPRI data folder, select `NPRI-INRP_IndustryIndustrie_Air_2015-2024` and click **Import**. [frame @01:12]
3. In the preview window click **Transform Data** to open the Power Query Editor. [video @01:17]
4. Confirm the columns: `Industry (English) / Industrie (Anglais)`, `Industry (French) / Industrie (Français)`, `Year / Année` (whole number), `NAICS Number / Numéro SCIAN`, `Total - Releases to Air (tonnes) / Total - Rejets dans l'air (tonnes)`, `Facility Count / Nombres d'installations`. APPLIED STEPS = Source, Promoted Headers, Changed Type. [frame @01:22]

### B. Prepare: remove nulls in the column to pivot, and drop columns that break row identity
5. Click the filter arrow on `Year / Année`, untick **(null)**, click **OK** (one row in this file is entirely null; pivoting with it fails). Step "Filtered Rows" is added. [video @03:22-04:12; frame @03:42, @04:12]
6. Select the `Facility Count / Nombres d'installations` column and remove it (`Home > Manage Columns > Remove Columns`, or right-click > Remove). Step "Removed Columns". Reason: every column you do NOT pivot is treated as a row identifier; Facility Count differs year to year, so keeping it gives one row per industry-and-count combination with mostly `null` year cells. [video @04:52-05:52; frame @05:52]

### C. Long to wide (Pivot Column)
7. Click the header of the column whose values become the new column names: `Year / Année`. [video @06:05]
8. Click `Transform > Any Column > Pivot Column`. [video @02:27; frame @02:32]
9. In the "Pivot Column" dialog ("Use the names in column "Year / Année" to create new columns.") set **Values Column** = `Total - Releases to Air (tonnes) / Total - Rejets dans l'air (tonnes)`. Leave "Advanced options" collapsed (default aggregation). Click **OK**. [video @02:40, @06:14; frame @02:42, @03:12]
10. Result: one row per industry; columns `2019`, `2018`, `2021`, `2020`, `2023`, ... (in the order they first appear in the data) holding the release values. Step "Pivoted Column". [frame @06:42]
11. Optional: drag the year column headers into chronological order; step "Reordered Columns" is added. [video @04:24, @06:39; frame @04:32, @06:52]

### D. Wide to long (Unpivot)
12. Click the first year column header, then **Shift+click** the last year column header to select all year columns. [video @07:06; frame @07:12]
13. Click `Transform > Any Column > Unpivot Columns` (dropdown also offers **Unpivot Other Columns** and **Unpivot Only Selected Columns**). [video @07:20; frame @07:12]
14. Result: the year columns collapse into two columns, `Attribute` (year) and `Value` (releases); step "Unpivoted Columns". [frame @07:32]
15. Optional: rename `Attribute`/`Value` (double-click header) and set types (general knowledge — not shown in course). Then `Home > Close & Load` to send the result to a sheet.

## Formulas / expressions / code
M code generated by the steps (formula bar, as shown):
```
= Table.SelectRows(#"Changed Type", each ([#"Year / Année"] <> null))
```
Filtered Rows: keep rows where Year is not null.
```
= Table.RemoveColumns(#"Filtered Rows",{"Facility Count / Nombres d'installations"})
```
Removed Columns: drop the column that would break row identity.
```
= Table.Pivot(Table.TransformColumnTypes(#"Removed Columns", {{"Year / Année", type text}}, "en-CA"), List.Distinct(Table.TransformColumnTypes(#"Removed Columns", {{"Year / Année", type text}}, "en-CA")[#"Year / Année"]), ...
```
Pivoted Column: converts Year to text (new column names), takes the distinct years as the new columns, fills them from the Values Column (rest of line cut off on screen).
```
= Table.ReorderColumns(#"Pivoted Column",{"Industry (English) / Industrie (Anglais)", "Industry (French) / Industrie (Français)", "NAICS Number / Numéro SCIAN", "2019", "2018", "2021", "2020", "2022", "2023", "2017", ...
```
Reordered Columns: produced by dragging headers.
```
= Table.UnpivotOtherColumns(#"Reordered Columns", {"Industry (English) / Industrie (Anglais)", "Industry (French) / Industrie (Français)", "NAICS Number / Numéro SCIAN"}, "Attribute", "Value")
```
Unpivoted Columns: note that selecting the year columns and choosing "Unpivot Columns" records `Table.UnpivotOtherColumns` listing the ID columns to keep.

## Verify
- After pivot: one row per industry (no repeated industry names), year columns filled with numbers and few `null`s. [frame @06:42]
- After unpivot: columns are the three ID columns + `Attribute` + `Value`, and the row count is back near the original long length (fewer only where pivot cells were null).

## Pitfalls
- **Expression.Error: We cannot convert the value null to type Text.** appears after Pivot Column when the pivot column contains a null. Delete the "Pivoted Column" step (X next to it in APPLIED STEPS), filter out (null) on `Year / Année`, and pivot again. [video @03:11; frame @03:22]
- **Many `null` cells after pivoting** = an extra column (here `Facility Count`) varies across years, so rows are not unique per industry. Delete the pivot step, remove that column, re-pivot. [video @04:47-05:52; frame @04:22]
- New year columns come out in data order (2019, 2018, 2021...), not chronological; reorder by dragging if needed. [video @04:20]
- The title card on this video says "Selecting and removing columns and rows" but the content is pivoting. [frame @00:02]
